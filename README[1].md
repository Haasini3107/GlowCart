# GlowCart

Full-stack skincare shopping website.

## Frontend
Deploy `index.html` to GitHub Pages.

## Backend
Deploy this folder to Render as a Web Service.
- Build Command: `npm install`
- Start Command: `npm start`

## Render environment variables
- `RESEND_API_KEY` = your Resend API key
- `EMAIL_FROM` = `onboarding@resend.dev` for testing, or a verified sender/domain in Resend

Features:
- Registration + welcome email
- Real login validation
- Login-success email
- Product search/sort
- Cart and quantity controls
- Saved delivery addresses
- Checkout and orders
- Order confirmation email
- LocalStorage for cart/address/order history
